# What is Kubernetes?

Kubernetes (K8s) is an open-source **container orchestration platform** used to deploy, manage, and scale containerized applications.

It automates many operational tasks such as:

* Application deployment
* Scaling applications
* Load balancing
* Self-healing of failed containers
* Managing containerized workloads

### Kubernetes Architecture

Kubernetes consists of:

#### Control Plane (Master Node)

Responsible for managing the cluster.

Components include:

* API Server
* ETCD
* Controller Manager
* Scheduler

#### Worker Nodes

Responsible for running application workloads inside containers.

---

# Why Kubernetes is Needed

Managing containers manually becomes difficult as applications grow. Kubernetes solves this problem by providing automation and centralized management.

### Benefits

* Automatically restarts failed applications
* Manages applications across multiple nodes
* Scales applications based on demand
* Simplifies application deployment and updates
* Improves availability and reliability
* Organizes and connects microservices efficiently

# Basic Kubernetes Commands

### View Available Resources

```bash
kubectl api-resources
```

Lists all Kubernetes resource types available in the cluster.

---

### Get Resources

```bash
kubectl get pods
kubectl get deployments
kubectl get services
```

Displays information about cluster resources.

---

### Describe Resources

```bash
kubectl describe pod <pod-name>
kubectl describe deployment <deployment-name>
```

Shows detailed information about a specific resource.

---

### View Logs

```bash
kubectl logs <pod-name>
```

Displays logs generated by a container running inside a pod.

---

### Commonly Used Commands

```bash
kubectl get all
kubectl get nodes
kubectl get namespaces
kubectl create deployment nginx --image=nginx
kubectl delete pod <pod-name>
kubectl delete deployment <deployment-name>
```
